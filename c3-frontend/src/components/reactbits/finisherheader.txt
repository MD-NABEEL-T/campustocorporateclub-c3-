to implement in any page
Install
1. Add finisher-header class to the HTML element holding your header. The animated header will fill up the space of your header, so make sure it has a width and height (and is not just an empty HTML element).
<body>
  <div class="header finisher-header" style="width: 100%; height: 300px;">
    Logo, navigation, etc.
  </div>
  ...
</body>
2. Download finisher-header.es5.min.js and include it on the page (preferably before the closing </body> tag). The script is lightweight (2Kb gzipped).
<script src="finisher-header.es5.min.js" type="text/javascript"></script>
3. Initialize the header with your unique configuration. Make sure this is called only after including finisher-header.es5.min.js.
<script type="text/javascript">
new FinisherHeader({
  "count": 10,
  "size": {
    "min": 1300,
    "max": 1450,
    "pulse": 0
  },
  "speed": {
    "x": {
      "min": 0.1,
      "max": 0.6
    },
    "y": {
      "min": 0.1,
      "max": 0.6
    }
  },
  "colors": {
    "background": "#151515",
    "particles": [
      "#5c78ac",
      "#03070f",
      "#52588e",
      "#000000",
      "#362f82"
    ]
  },
  "blending": "overlay",
  "opacity": {
    "center": 0.5,
    "edge": 0.05
  },
  "skew": -2,
  "shapes": [
    "c"
  ]
});
</script>
